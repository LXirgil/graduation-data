# 実験計画書（案）

## 研究目的
Bank Marketingデータを用いて、学習データ量と少数クラスの比率が分類性能に与える影響を調べる。

## データセット
- UCI Bank Marketing（ID: 222）
- 出典: Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306
- 目的変数: `y`
- 少数クラス: `yes`
- 特徴量から除外する列: `duration`
- 欠損値数は特徴量ごとに確認して記録する。

## 変える条件
- 学習データ量: 500 / 1,000 / 2,000 / 5,000件
- 学習データ中の `yes` の比率: 50% / 30% / 10% / 5% / 1%
- 学習データの抽出に使う乱数シード: 42 / 43 / 44 / 45 / 46

各条件で必要な `yes` と `no` の件数を指定して、学習データから重複なしで抽出する。
条件を満たす件数を抽出できない場合は、その条件を実行せず理由を記録する。

## 固定する条件
- 全体の30%をテストデータとして最初に分割する。
- 分割時にクラス比率を保ち、乱数シードは42に固定する。
- 同じテストデータを全実験で使用する。
- 欠損値補完とカテゴリ変換の方法を全実験で統一する。
- 前処理は各実験の学習データだけで学習し、テストデータには変換のみ適用する。
- クラス重み付けや追加の不均衡対策は行わない。

## 欠損値・前処理（案）
- カテゴリ列の欠損値は `Unknown` として扱う。
- 数値列の欠損値は、その実験の学習データの中央値で補完する。
- カテゴリ列は One-Hot Encoding する。
- 数値列は標準化する。
- `duration` は前処理前に除外する。

## 比較するモデル
- ロジスティック回帰（`max_iter=2000`、その他は初期設定）
- ランダムフォレスト（木の数200、その他は初期設定）
- 乱数シードを使うモデルは、各実験の学習データ抽出と同じシードを設定する。

## 評価指標
- Accuracy
- 少数クラス `yes` のPrecision、Recall、F1（判定しきい値0.5）
- PR-AUC（Average Precisionとして計算）

5つの乱数シードで得た各指標について、平均と標準偏差を報告する。
