# 卒業論文の構成案

## 仮題

**学習データの量と少数クラスの割合が銀行マーケティングの申込予測に与える影響**

## 論文の中心となる問い

銀行の電話案内記録を使って申込の有無を予測するとき、学習データの件数と、学習データ中に申込ありの記録が占める割合は、申込ありの人を見つける性能にどう関係するか。

## 章立て案

### 要旨

- 何を明らかにしたい研究か
- 使用したデータ、モデル、実験条件
- 主な結果：申込ありの比率と Recall の関係、正解率だけでは見逃しが分からないこと
- 結果から言える範囲と主な限界

### 第1章　序論

#### 1.1 研究背景

- 分類予測では、片方のクラスが大多数を占めるデータがある。
- 多数クラスを当てるだけでも正解率が高くなり、少数クラスの見逃しが見えにくくなる。
- 銀行の電話案内記録では、申込ありより申込なしの記録が多い。

#### 1.2 問題意識

- 申込ありの例が少ないと、モデルが申込ありをどれほど見つけられるかが問題となる。
- 学習データ件数と、学習データに含める申込ありの割合を分けて比較する。

#### 1.3 研究目的・研究課題

本研究の目的は、学習データの量と申込ありの割合を変え、2種類の分類モデルにおける性能の変化を記述的に比較することである。

1. 学習データ量の違いは、申込ありの Recall と F1 にどう関係するか。
2. 学習データ中の申込あり比率の違いは、Recall と F1 にどう関係するか。
3. ロジスティック回帰とランダムフォレストで傾向に違いがあるか。
4. 正解率と少数クラスの評価指標を併せて見る必要性は何か。

#### 1.4 本研究の範囲

- 実データを用いた予測性能の比較を行う。
- 電話案内の方法を変えたときに申込件数が増えるか、実運用に有効かは検証しない。

#### 1.5 論文の構成

各章で扱う内容を簡潔に予告する。

### 第2章　関連知識とデータセット

#### 2.1 クラス不均衡と評価指標

- クラス不均衡の説明
- Accuracy（正解率）、Precision（適合率）、Recall（再現率）、F1、PR-AUC（Average Precision）の定義
- 本研究で Recall を重視する理由と、他の指標も併記する理由

#### 2.2 Bank Marketing データセット

- UCI Machine Learning Repository の Bank Marketing データを使用する。
- 全45,211件、特徴量16項目。
- 目的変数 `y` は申込あり `yes` 5,289件、申込なし `no` 39,922件。
- 元データで申込ありは約11.7%。
- データ出典：Moro, S., Rita, P., & Cortez, P. (2014). *Bank Marketing* [Dataset]. UCI Machine Learning Repository. https://doi.org/10.24432/C5K306

#### 2.3 予測時点に関する特徴量の扱い

- `duration`（通話時間）は案内終了後に判明する情報のため、予測特徴量から除外した。
- 研究で使う特徴量と除外する理由を記載する。

### 第3章　実験方法

#### 3.1 データ分割

- データ全体を層化抽出で学習用70%、テスト用30%に分割した。
- 分割用乱数シードは42とし、全条件で同じテスト用データを使用した。
- 学習用31,647件、テスト用13,564件。テスト用の申込ありは1,587件。

#### 3.2 学習データ量と申込あり比率

- 学習データ量：500、1,000、2,000、5,000件。
- 申込あり比率：1%、5%、10%、30%、50%。
- 各条件の件数を指定し、学習用データから重複なしで抽出した。
- 条件ごとに5つの乱数シード（42〜46）で抽出した。

#### 3.3 比較モデル

- ロジスティック回帰（`max_iter=2000`）
- ランダムフォレスト（決定木200本）
- クラス重み付けやその他の不均衡対策は適用していない。

#### 3.4 前処理

- 数値項目は学習データの中央値で欠損値を補完し、標準化した。
- カテゴリ項目は欠損値を `Unknown` として扱い、One-Hot Encoding した。
- 前処理は各条件の学習データで適合し、テストデータには変換のみ適用した。

#### 3.5 評価指標と実験回数

- Accuracy、申込ありのPrecision・Recall・F1、PR-AUC（Average Precision）を算出した。
- 分類判定のしきい値は0.5に固定した。
- 4種類のデータ量 × 5種類の比率 × 5つの抽出シード × 2モデルで計200回。
- 条件の未実行は0件。

### 第4章　実験結果

#### 4.1 実験の実行状況

- 200回の実験を完了した。
- 条件ごとに5回の平均と標準偏差を計算した。
- 集計表は [`../results/summary.csv`](../results/summary.csv)、全実行記録は [`../results/results_2026-10-26.csv`](../results/results_2026-10-26.csv)。

#### 4.2 学習データ量による違い

- 申込あり比率5条件の平均Recallは、データ量500件から5,000件に増やしたとき、ロジスティック回帰で約1.2ポイント、ランダムフォレストで約3.7ポイント増加した。
- 比率別の値と標準偏差を表・図で提示し、平均値だけで「データ量は影響しない」と結論づけない。

#### 4.3 申込あり比率による違い

- 比率1%から50%にしたときの平均Recallの差は、ロジスティック回帰で約63.8ポイント、ランダムフォレストで約66.9ポイント。
- 比率1%では平均正解率が約88%でも、Recall はロジスティック回帰で約0.3%、ランダムフォレストで0%だった。
- 比率30%ではF1がロジスティック回帰約41.2%、ランダムフォレスト約43.3%で、今回の比率条件の中で最も高かった。
- 比率50%ではRecallが最も高いが、F1は30%条件より低かった。

#### 4.4 モデル間の比較

- Recall、F1、Accuracy、PR-AUCを並べ、指標によってモデルの比較結果が異なる点を示す。
- 個別の優劣を一般化せず、今回のデータ・条件に限る。

### 第5章　考察

#### 5.1 正解率と見逃し

不均衡なデータでは、多数クラスを多く当てることで正解率が高くなり得る。申込ありの発見を評価するには、Recall、F1、PR-AUCなどを併せて確認する必要がある。

#### 5.2 学習データ中の申込あり比率の影響

今回の条件では、学習データ量の増加よりも、申込あり比率の増加がRecallの変化と強く結びついていた。比率30%はF1、50%はRecallが高いという違いから、評価基準によって条件の見方が変わる。

#### 5.3 モデルの違い

両モデルは概ね似た傾向を示した。ランダムフォレストは比率30%・50%でRecallやF1が高かったが、低比率では両モデルとも申込ありをほとんど発見できなかった。

#### 5.4 実用上の解釈

今回の実験で比率を上げた条件は、公開データから申込ありの例を多く含む学習データを選んだ比較であり、新しい記録を作成・収集したものではない。このため、実運用で申込ありデータを増やす方法や費用対効果は本研究の結果から直接判断できない。

### 第6章　限界と今後の課題

- テストデータ分割は1回に固定しており、別分割での再現性は確認していない。
- 5つの抽出シードによる記述的な比較で、統計的有意差の検定はしていない。
- しきい値0.5に固定し、しきい値調整やクラス重み付けは行っていない。
- モデルは2種類に限定している。
- 今後の課題として、複数のテスト分割、判定しきい値、クラス重み付けなどを追加で調べる余地がある。

### 第7章　結論

- 研究課題に対する答えを、結果の数値とともに簡潔にまとめる。
- 今回の実験範囲では、申込あり比率の違いがRecallと強く関係したことを述べる。
- 正解率だけでは少数クラスの見逃しを把握できないことを述べる。
- 他データ・別モデル・実運用にそのまま一般化できないことを明記する。
